# Помощник — стартовый проект

Это начальная рабочая основа Telegram-бота и Mini App. Она не копирует внутренний код другого бота; внешний вид и функции будем дорабатывать по предоставленным скриншотам/видео.

## Что уже есть
- `/start` и кнопка открытия Mini App (если задан `WEBAPP_URL`)
- тёмный интерфейс с фиолетовыми акцентами
- заготовки разделов: студенты, расписание, посещаемость, журнал, база знаний, объявления
- SQLite и начальная таблица студентов
- `/health` для проверки бота и HTTP endpoint `/health`

## Переменные окружения
- `BOT_TOKEN` — токен от @BotFather. Не публикуйте его и не добавляйте в Git.
- `WEBAPP_URL` — публичный HTTPS-адрес размещённого приложения.
- `PORT` — порт сервера (обычно задаёт хостинг).
- `DB_PATH` — путь к SQLite-файлу.

## Локальный запуск
1. Установите Python 3.11 или новее.
2. Установите зависимости: `pip install -r requirements.txt`
3. Создайте переменные окружения на основе `.env.example` (не загружайте `.env` в Git).
4. Запустите: `python bot.py`

Для локального запуска приложение доступно по адресу `http://127.0.0.1:8080`, но Telegram Mini App требует публичный HTTPS URL.

## Важно
- Не отправляйте токен бота в чаты и не вставляйте его в исходный код.
- Перед реальным использованием нужно добавить проверку Telegram Web App initData на сервере, роли пользователей, защиту API и полноценные формы CRUD.
- На хостинге проверьте, что постоянное хранилище подключено: временная файловая система может стереть SQLite после перезапуска.
